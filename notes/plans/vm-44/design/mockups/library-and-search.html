VM-44 mockups — the Library and search

VM-44 mockups — the Library and search. Today the phone’s Library is the 200 most recently touched notes from all nine wings with a silent cut, an untitled note is a raw date printed twice, there is no preview, and search reads titles only: “ferry” finds nothing though several notes contain it.

“showing preview more lot apple notes so i know what each note is.” · “it’s hard to find items in the library.”

The Library here is one wing’s notes under the ruled shell. The note row is still open (LS-1), so its alternatives are drawn once, small; the grader’s pick, (b), is carried through the rest. Stamps are the Mac’s time words (“today 2:14 PM”, “yesterday”, “Nov 10”). Pool and Snippets are the Mac’s names for today’s Bookless and Scraps (LS-3’s lean, not yet ruled).
