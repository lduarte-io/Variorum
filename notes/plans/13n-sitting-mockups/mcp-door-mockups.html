6 · The paper trail — commits and undo

On the edit rung, every AI change to a take is bracketed by named commits — the insurance occasion you already ruled for cross-block edits, extended to a third writer. And every structural act an assistant takes registers structural undo exactly like your own gestures: ⌥⌘Z walks back an AI session one act at a time, and one bulk import is one entry — a whole imported book comes back out in a single press. Option: whether consecutive AI acts coalesce into one entry per working session, or stay one entry per act (my lean: per act, with the bulk doors compound — honest granularity, and the big undo people dream of lives on the doors that do big things).

8 · Level 0 — the Variorum document format

The import format is the export format — the fan export's “Alternates” sections, already shipped, already proven as the app's own voice (your 2026-07-25 intake was one). Round-trip by construction: any LLM that has seen one export can author an import, connection or no connection. The chosen take sits in place; the rest of the fan follows in its section; {t:"…"} and {#tag} are the capture microsyntax you already have. Paragraph = block on entry, the standing bulk rule. One import = one note (or one book from a folder of these) = one undo entry.

{t:"o ladrão de raios — ch 1"} {#percy/pt-en} Eu não pedi para herdar o observatório. Se você está lendo isto porque acha que pode ser um, meu conselho é: devolva a chave ao barqueiro. --- Alternates for this block --- take: "english" Honestly, I never asked for the observatory. If you're reading this because you think you might be one, my advice is: close this book right now. --- end alternates --- Cuidar de um observatório dá trabalho. É assustador. Na maior parte do tempo, você perde o barco da maré e espera até amanhã. --- Alternates for this block --- take: "english" Running an observatory is hard work. It's lonely. Most of the time, it leaves you stranded waiting on the tide. --- end alternates ---

The import door: File ▸ Import, or drop the file on the Bookcase. The in-place text becomes each block's chosen take; labeled takes join the fan unlabeled-never-chosen; the title and tags come from the braces. The export pin stands untouched — exports still never write a row; import is its own door, minting fresh rows through ordinary operations, never “reconciling” a file as truth.

9 · The tool vocabulary — one lean set, four rungs

Tools are thin projections of the operations layer; the rung decides which exist for a given grant. Every refusal a door would speak to you is spoken to the client in the same words. Nothing here is raw SQL, nothing can hard-delete, and nothing can choose a take.

RUNGTOOLSTHE CONTRACT
readlist_books · list_notes · read_note · search · export_noteReads scope-checked against the grant on every call; read_note returns blocks, takes, comments in the Level 0 format; search is the 13o engine filtered to scope.
suggestadd_take · add_comment · save_lensNew takes land at the fan's end, labeled, never chosen, never locked. Provably cannot modify an existing take — pinned by test like any refusal.
write newcreate_note · import_document · apply_tag · create_book · add_note_to_bookCreative acts that still touch no word of yours. import_document is the bulk door — the Level 0 format as payload, one compound undo entry.
editedit_take · divide_block · merge_blocks · move_block · delete_blockedit_take requires the expected text (stale reads refuse as bufferChangedSinceGesture) and is bracketed by the named before/after commits. delete_block is a tombstone — the tray catches it.

10 · The plumbing, in one breath

A tiny variorum-mcp helper ships inside the app bundle. Claude Code (and Claude Desktop's config file) launch it over stdio; it forwards to the running app over a unix socket in the app's own container — no TCP port, no network service, exactly §9's lean. The app is the only process that ever touches the store; grants live in a local-only table (no sync, no lockstep, marker untouched); the socket dies with the app. On Castle exactly as on Standard: the app is already the unlocked custodian, so the client brings no key and sees no key — a grant is the disclosure, and a local model means nothing leaves the machine at all.
