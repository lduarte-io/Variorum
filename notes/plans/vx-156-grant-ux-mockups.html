11 · Agenda (d) — the A-4 options, honestly recommended: L1 now · K0 for launch · K2 if wanted

A client is whoever it says it is when it connects, and every client arrives through the same shim, so the socket can't tell them apart. A secret in the client's config would stop two tools from sharing a name by accident — it would not stop a program running as her, because the config file is readable by anything she runs. Found while preparing this: the canon says the pane states this boundary, but no line in the pane does. L1 adds it, whichever option she picks.
