Four mockups for the use-report round

Static states, side by side, in the Study voice's grammar (paper, serif prose, blue accent, the brown ring). Each figure is the shape the plan describes; the captions name what is fixed by ruling and what is the implementer's latitude. Nothing here is a pixel spec — spacing follows the app's own tokens and the pre-13u mockup style guide.

A · Divide choosing takes replaces "Divide with Ceremony…" everywhere — the sheet is now the ONE door for every arrangement

What changed and why. The arrangement is chosen FIRST, in one row of four, and the default is your ruling — keep the takes on the top block. Choosing a preset places every ✂ for you; the columns below only show what will happen. Only the fourth option, "Choose per take", turns the columns into the hand-placement surface (checkboxes, draggable ✂, ⇥ between takes). The prose reads as prose: no gaps between words — the ✂ is drawn over the inter-word gap and the layout never moves when it does. Takes sit side by side (up to three columns; each column scrolls on its own beyond that) — no more scrolling a stack to find the second take.

C · The sidebar's note box a book in an editing mode — the box stands where the "this note" rail stands for a note, at the rail's exact height

What it is. When a BOOK is open in Outline, Index or Book (never Read), the sidebar shows this box instead of the mode rail. It holds the focused note's controls — the same bar that floated at the right — plus what is worth knowing about the note without leaving the sidebar. Three states, left to right: nothing selected · a note selected but not live · a note live under the caret. The box never changes height between states, so the Open strip below it never jumps. The right gutter and the floating card retire.

Under it, one filter row — all · blocks · takes — so "6 deleted takes" is no longer a fold you have to find under the block cards. The explainer shrinks to one line per view; the cards name their kind. Put back / Delete Now stay exactly where they were.
