**VX-959 — THE CHOICE (written before any fix): serialize the bind road per socket path, in-process.** Every host's road from its pre-bind check to its publish decision — the owed re-check, `MCPSocketRoad.listen` (probe → unlink → bind → chmod → listen), the wake pipe, then the publish re-check and either the publish or its OWN cleanup — runs under ONE lock per socket path. Why this, over a stat-after-bind identity carried with the fd:
- it closes ALL FOUR roads at once: inside the lock no other host's probe can land in a bind → listen gap (A), no two probes can both pass (B), no fresh probe can meet a listener that is not yet decided (C — the fresh start waits, then binds the freed path), and a host's second start meets its own published state, not its own half-built listener (D);
- **what closes the check-then-unlink gap:** the publish re-check and the cleanup's unlink run under the same lock every in-process `bind` of that path needs, so nothing can rebind the path between the check and the unlink — the gap the identity check cannot close by itself (macOS has no conditional unlink: a `stat` → compare → `unlink` leaves a window), and the identity has a second gap of its own (a steal between `bind` and the `stat` that records it would make the host record the STEALER's identity and later remove it);
- the identity would leave B, C and D open (B's unlink is the deliberate stale-file replace, whose target has no recorded identity; C and D unlink nothing).
`halt`'s and `listenerDied`'s unlinks stay outside the lock: with the bind road serialized, no in-process host binds a path whose published listener still answers, so the file each removes is its own; and a stop never waits on a start. **Residual (stated, not built):** two PROCESSES on one container (a second instance of the same app) — an in-process lock does not reach them; a lock across processes needs either a lock file (a new file in the container — this batch's stop condition) or `flock` on the socket directory itself; the probe still refuses a live second instance as before.
