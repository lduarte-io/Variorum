# Variorum — shorts scripts (video section)

Scripts for short-form vertical video (Instagram Reels, TikTok, YouTube Shorts),
drafted 2026-09-26. The frame for the whole series is **build-in-public**: "I'm
building myself a writing app because…" — no download CTA needed, the ask is a
follow. Every script is one idea, one gesture, demonstrated end to end.

## The shape (every script follows it)

1. **HOOK** (0–3s) — the pain or the stunt, cold open, no logo, no talking head.
2. **PAIN** (~3–10s) — name the universal writer behavior the viewer recognizes.
3. **TURN** (~10–15s) — "so I built…" — cut to Variorum, calm page.
4. **DEMO** (~15–32s) — the one gesture, real screen capture, nothing else.
5. **KICKER** (last 5–10s) — the line + the name + the follow ask.

Target length 35–45s. VO lines are written short enough to double as burned-in
captions verbatim.
