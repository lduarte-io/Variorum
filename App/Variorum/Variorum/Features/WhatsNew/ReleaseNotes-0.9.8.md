**Gatherings and tags, more honest.**
- Deleting a tag can now be undone — ⌥⌘Z brings back the tag, its sub-tags and everywhere it was applied, and the delete confirm no longer claims otherwise.
- Adding an existing note to a gathering that collects starred notes now stars the note for you; the receipt says so, and the star limit never blocks it.
- New notes can be made inside a gathering whose rule uses "not", as long as a fresh note can satisfy the rule; a rule that contradicts itself still greys the button, with the reason on hover.
- The receipts for making or adding notes in gatherings are shorter: "Tagged #essays — the gathering shows it now."
- Adding a note to an archived gathering tells the truth: the tags apply, and the gathering shows it once it's unarchived.
- A greyed new-note button explains itself in one short sentence, like "Archived — unarchive it to add notes."
- The notice when you edit a note that lives in several books counts books only — gatherings no longer inflate it.
- Disabled buttons look disabled everywhere: the calm button style fades and stops answering hover when a button can't act.
- While your library is opening, the Settings window says "Opening your library…" instead of asking you to open the main window first.

**Books, easier to move through.**
- Opening a note from a book — "open ↗" or "Open in the full editor" — now lands in Write at the paragraph you were on, instead of at the top of the note in whatever mode it last used.
- "Edit here" in the book's note box returns to where you were just working in the book, not where you last were in the note's own editor.
- The note box offers "open ↗" in every book mode, so you can leave for Write however far the note's title has scrolled away.
- In a book's Index, paragraphs with takes wear a small ⑂ badge; clicking it (or the box's "takes") opens that paragraph's takes right there, over the book.
- Switching from Outline to Index keeps your paragraph live, with the caret where you left it.
- The little ▸ that unfolds a note in a book is a real target now — bigger, with a hover glow — and a near miss no longer throws you out of the book. The chapter folds in Index grew the same way.
- The Book Panel no longer shows drag bars beside chapters when the book is date-ordered and nothing can be placed by hand.
- The Bookcase's order menu closes on Escape, like any menu.

**A sweep of small fixes before launch.**
- ⌘S commits the moment you leave the name field — click away, keep typing, or close the window; only ⎋ means don't save.
- Hover any "edited" or "created" stamp to see the exact date and time, everywhere one shows — the Library's info panel and the book's note box included.
- The Library adapts to narrow windows: search collapses to a 🔍 button that still searches, the info panel stays whole, and nothing is cut off.
- The doubled line under the Library's "Notes" header is one line again.
- The Library's controls wear the voice's colour in dark Terminal instead of system blue.
- A note duplicated from a Library row shows up in the list immediately.
- The Pool has a home for quiet confirmations — duplicates, undo and redo now speak at its foot.
- An AI client granted an empty wing can find it: the new list_wings tool names the wings you shared, so it can make its first book there without help.
- Sharing the same place with the same client again keeps one grant — the newest; revoking what you see revokes everything.
- When an AI client disconnects — or the server stops, or the library locks — the Activity list says so, with the reason.
- Text pasted or sent with a hidden null character is stored without it, and an AI that writes one is told how many were removed.
- Two Macs sharing a backup folder no longer prune each other's backups.
- If the sync hold's marker can't be removed, Resume Sync says so and keeps the banner instead of pretending.
