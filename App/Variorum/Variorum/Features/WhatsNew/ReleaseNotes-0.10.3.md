## Your notes travel as plain files, and the sidebar does more

Export any note as a markdown file with File ▸ Export Note… (⌥⌘S) — exactly what Copy full text gives you. Export Library now writes each note's title and tags into its file, so a whole bulk export re-imports complete. And a plain-text export now imports again in later versions of Variorum, across the library format's migrations.

- Right-click a note in the sidebar for Rename, Move or Copy to Wing, Export, Close, and Delete.
- Untitled notes show their first words in the sidebar instead of a date.
- A new setting can keep starred notes out of the Open list, so they appear only under Starred.
- Dragging an Open note down one slot now lands where you dropped it.
- Hover any icon for a short name of what it does.
- ⌘← and ⌘→ go back and forward, like the browser — inside your text they still move along the line.
- Find in Write shows where you are: 2 of 15, counting with you as you step.
- An untitled note's title offers its first line — or today's date — and Tab takes it.
- Coming back to the Bookcase puts the cursor in the new-note line, every time.
- The wing you're in shows beside every New Note button, so a new note never lands somewhere surprising.
- ⌥⌘N makes a new note inside the book you're reading.
- The Help menu says what it means: Restore Field Guide, Open the Field Guide, Take the Onboarding Tutorial.

Sharing with AI got more capable and more honest:

- A client can now hold grants on several wings at once — adding a second no longer drops the first.
- A gathering can be shared: scope a client to exactly what a rule collects.
- Shared with AI has a proper add door, and a fresh library now says the AI door starts closed.
- Adding a note to a book tells the client when the book's own tags were applied.
- If a connection drops quietly overnight, Activity now says so, and when.
