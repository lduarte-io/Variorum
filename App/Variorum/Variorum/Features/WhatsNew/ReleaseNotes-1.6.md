# Variorum 1.6

This update is about working inside a book. Tags now show on a book's outline cards and in a new List view, and you can add them right there; a new note lands on the page ready to type, from every door; and opening a library no longer waits on a slow backup folder.

- A book has a new List view — the Library's own rows, with titles, days, tags and edited stamps, in the book's order under its chapters.
- A per-book switch shows tags on the outline's cards and the List's rows: hidden, other tags, or all tags. "Other tags" leaves off the tags that already place a note in a gathering, to keep the page calm.
- Tags can be added right on a card: a small + beside a note's tags opens a field that suggests your most-used tags first. The add-tag shortcut (⌘⇧I) now works in books too, opening the field on the note you're on.
- A new note made in a book now ends up on the page, live, with the cursor in it — from every door. A chapter's own "+ new note" files it in that chapter; the other doors file it after the note you're on. Making a note while reading switches the book to the outline so it's ready to type.
- Picking an order on a gathering, or on a book that isn't hand-ordered, now saves it as the book's order at once. A hand-ordered book keeps picks as a way of looking, with "Save as this book's order" and "Back to manual order" shown while one is on.
- A long note title rests cut with an ellipsis and scrolls like a radio ticker under the pointer, one title at a time.
- Note titles can be shown while reading: a quiet line above each note in Read's scroll, remembered per book.
- Quick notes can be tagged as you write them — a tag button sits beside the title suggestion on the new-note box and on the menu-bar quick note.
- The × on a tag pill is centred with its text.
- The book navigator's view tabs now fit its narrowest width in the Terminal voice.
- Switching a book to its outline no longer shows a note's title over a blank card for a beat.
- Opening a library is fast again when a backup folder lives in iCloud: the open reads it in the background instead of waiting on it, and a restore list now says which place each copy comes from.
