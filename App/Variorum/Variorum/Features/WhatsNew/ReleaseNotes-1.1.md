# Variorum 1.1

- Syncing a large library now shows its progress — how much has arrived and how much remains — instead of a bare "Syncing…", and the first sync of a big library is several times faster.
- New for connected AI tools: create gatherings, copy notes between wings, and make precise text replacements. Errors are clearer, and a closed connection now tells the client why.
- Takes and Compare: switching modes with takes open no longer jumps, Compare no longer flickers when toggling views, comments now appear in Takes and Compare, and undated notes sort by the day they were written.
