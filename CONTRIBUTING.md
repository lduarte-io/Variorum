# Contributing

Variorum is open source, but it isn't open to contributions: I don't accept pull requests, patches or code from anyone else, and that isn't going to change.

## Why

Keeping one owner is what keeps the project's options open. As the only copyright holder, I can relicense the code, offer it under a second license beside the AGPL, and ship the iOS app through the App Store, whose terms the AGPL doesn't fit. A single outside contribution would end that. A contributor license agreement would only trade it for paperwork, so there is no CLA and there are no exceptions. It's the same stance SQLite takes: open source, closed contribution.

## What helps instead

- **Bugs and ideas:** open an issue. Every issue goes into my private work queue and is prioritized there with everything else.
- **Security problems:** please don't open a public issue. [SECURITY.md](SECURITY.md) says where to write.
- **Pull requests** are closed automatically with a short note pointing here. It's never a judgment on the change. If it fixes something, an issue describing the problem is the best way to get it fixed.
- **Your own version:** the [license](LICENSE) lets you fork Variorum and change it for yourself. If you distribute your version, the AGPL's terms travel with it.
