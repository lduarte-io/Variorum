# Security

If you've found a security problem in Variorum, please tell me privately rather than in a public issue.

## How to report

Email **support@stargazing.tech** with "security" in the subject line. Include what you found, the steps to reproduce it, and the version of Variorum you saw it in (Variorum ▸ About Variorum).

## What happens next

I read every report and will reply once I've confirmed what you found. The fix ships in a release, and its write-up is published with that release, never before it. If you'd like to be credited, say so and tell me how.

## Supported versions

Fixes land in the next release of the Mac app. Please check against the latest release before reporting.
